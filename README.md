# Pulse — Modern Admin Dashboard

A clean, responsive admin dashboard built with **React**, **TypeScript**, **Tailwind CSS**, and **Vite**.

## Features

- Collapsible sidebar navigation
- Stats cards with trend indicators
- Revenue area chart & traffic pie chart (Recharts)
- Orders data table with status badges
- Analytics, Customers, and Settings pages
- Fully responsive (mobile + desktop)
- Dark theme UI
- Ready for Netlify deploy

## Tech Stack

- React 19 + TypeScript
- Vite
- Tailwind CSS v4
- React Router
- Recharts
- Framer Motion
- Lucide React

## Getting Started

```bash
npm install
npm run dev
```

```bash
npm run build
npm run preview
```

## Deploy on Netlify

1. Import this repo on [Netlify](https://app.netlify.com)
2. Build settings are in `netlify.toml` (auto-detected)
3. Deploy
